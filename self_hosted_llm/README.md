# Myntra Self-Hosted LLM Service
On-premise content moderation and fast inference using Llama 3.1.
Zero data egress — all inference runs within Myntra's Azure VMs.

**Asset type:** 3rd Party Model (Hosted)
**Models:** Llama 3.1 8B via Ollama (GPU), Llama 3.1 8B GGUF via llama.cpp (CPU)
**Hosting:** Azure VM (Standard_NC6s_v3) — no data leaves Myntra infra
**Use case:** UGC content moderation, fast keyword generation
