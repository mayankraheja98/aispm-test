# Myntra Style Assistant Skill

Provides Claude with access to Myntra's product catalog and styling expertise.

## Tools

- `search_products(query, category, filters)` — Semantic product search
- `get_outfit_suggestions(occasion, budget, style_preference)` — AI outfit builder
- `check_availability(product_id, size)` — Real-time stock check

## Setup

Requires `MYNTRA_API_KEY` and `MYNTRA_CATALOG_URL` in environment.
