# Myntra Content Generation Service
AI-powered content generation for product descriptions, SEO tags, and translations.
Uses multiple SaaS AI providers (Anthropic, OpenAI, Cohere) with fallback logic.

**Asset type:** 3rd Party Model (SaaS)
**Providers:** Anthropic Claude, OpenAI GPT-4o, Cohere embed-english-v3.0
**Use cases:** Product descriptions, SEO tags, embeddings, translation (EN→HI/TA/BN)
