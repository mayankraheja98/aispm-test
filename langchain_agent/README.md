# Myntra CX LangGraph Agent
Multi-turn customer service agent using LangGraph with tool calling.
Handles: order status, returns, product search, size recommendations.

**Asset type:** AI Agent (1st Party)
**Framework:** LangChain + LangGraph
**Model:** Claude 3.5 Sonnet (primary), GPT-4o (fallback)
**Tools:** search_catalog, check_order_status, initiate_return, get_size_recommendation
